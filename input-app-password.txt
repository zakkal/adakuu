================================================================
COPY APP PASSWORD KAMU DI SINI
================================================================

Setelah kamu generate App Password di Google, paste di file ini:

APP_PASSWORD: [PASTE DI SINI]


Contoh:
APP_PASSWORD: abcd efgh ijkl mnop

Atau tanpa spasi:
APP_PASSWORD: abcdefghijklmnop


Setelah paste, save file ini dan jalankan:
php apply-app-password.php

================================================================
CARA GENERATE APP PASSWORD (dari screenshot kamu):
================================================================

1. Kamu sudah di: https://myaccount.google.com/apppasswords
2. Klik tombol "Buat" atau "Create" atau "+ Add"
3. Nama aplikasi: "Adakuu Website"
4. Klik Generate/Buat
5. Copy password 16 karakter yang muncul
6. Paste di atas ↑
