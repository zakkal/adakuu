================================================================
OPTION 2: BUAT APP PASSWORD BARU (RECOMMENDED)
================================================================

1. DI HALAMAN SCREENSHOT
   ----------------------
   Klik tombol "Buat" atau "+ Create"
   
2. MUNCUL POPUP
   ------------
   - Nama aplikasi: Ketik "Adakuu Website"
   - Klik "Buat" / "Generate"
   
3. MUNCUL PASSWORD
   ---------------
   Akan muncul 16 karakter password:
   
   ┌─────────────────────────┐
   │  abcd efgh ijkl mnop    │  ← Contoh
   └─────────────────────────┘
   
   Klik icon COPY atau select & Ctrl+C

4. SIMPAN PASSWORD
   ---------------
   ⚠️ PENTING: Password hanya muncul 1x!
   Save di notepad dulu kalau perlu.

5. JALANKAN SETUP
   --------------
   Buka CMD/Terminal (Win+R → ketik "cmd"):
   
   cd c:\jualakun
   php setup-smtp-interactive.php
   
   Atau double-click: setup-gmail.bat

6. PASTE PASSWORD
   --------------
   Script akan minta App Password.
   Paste (Ctrl+V) password yang tadi kamu copy.
   
   Boleh:
   - abcd efgh ijkl mnop (dengan spasi) ✅
   - abcdefghijklmnop (tanpa spasi) ✅
   
   Script akan auto-clean spasi.

7. TUNGGU
   ------
   Script akan:
   - Update .env
   - Clear cache
   - Test email
   
8. BERHASIL!
   ---------
   Jika muncul: "✅ SUKSES!"
   
   Cek email di: zaki.alghifari0306@gmail.com
   (Cek inbox DAN spam folder)

================================================================
TROUBLESHOOTING
================================================================

ERROR: "BadCredentials"
→ App Password salah atau 2FA belum aktif
→ Generate password baru dan coba lagi

ERROR: "Connection refused"  
→ Internet bermasalah atau firewall block port 587

Email tidak masuk inbox
→ Tunggu 1-2 menit
→ Cek folder SPAM
→ Pastikan email shoppinghere@shoppinghere.biz.id bisa login
