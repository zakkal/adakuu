====================================
SETUP GMAIL SMTP - STEP BY STEP
====================================

LANGKAH 1: CEK 2-FACTOR AUTHENTICATION
--------------------------------------
1. Buka: https://myaccount.google.com/security
2. Cari "2-Step Verification"
3. Pastikan STATUS: ON (aktif)
4. Jika belum aktif, AKTIFKAN DULU!

LANGKAH 2: GENERATE APP PASSWORD
---------------------------------
1. Buka: https://myaccount.google.com/apppasswords
   
   ATAU
   
   Google Account → Security → 2-Step Verification → 
   Scroll ke bawah → App passwords

2. Klik "Generate" atau "Create app password"

3. Pilih:
   - Select app: "Mail"
   - Select device: "Other (Custom name)"
   - Ketik: "Adakuu Website"

4. Klik "Generate"

5. COPY PASSWORD 16 KARAKTER
   Format: xxxx xxxx xxxx xxxx (dengan spasi)
   Contoh: abcd efgh ijkl mnop

6. HAPUS SEMUA SPASI!
   Yang benar: abcdefghijklmnop (tanpa spasi!)

LANGKAH 3: UPDATE .ENV FILE
----------------------------
Buka file: c:\jualakun\.env

Cari bagian MAIL, ubah jadi:

MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=shoppinghere@shoppinghere.biz.id
MAIL_PASSWORD="xxxxxxxxxxxxxxxx"
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@adakuu.com"
MAIL_FROM_NAME="Adakuu"

Ganti xxxxxxxxxxxxxxxx dengan App Password 16 karakter (TANPA SPASI)!

LANGKAH 4: TEST
---------------
1. Buka terminal/cmd di: c:\jualakun

2. Jalankan:
   php artisan config:clear

3. Test kirim email:
   php test-email.php

4. Jika BERHASIL, akan muncul:
   ✓ Email berhasil dikirim

5. CEK INBOX: zaki.alghifari0306@gmail.com
   (juga cek folder SPAM!)

TROUBLESHOOTING
---------------
Error: "BadCredentials" atau "Username and Password not accepted"
→ App Password salah atau 2FA belum aktif

Error: "Connection refused"
→ Port atau host salah (harusnya smtp.gmail.com:587)

Email tidak masuk inbox
→ Cek folder SPAM
→ Tunggu 1-2 menit
